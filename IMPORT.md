# Installation

## Development

Include the `:email-verification` Gradle project from this source checkout and add `implementation(project(":email-verification"))`. See [Integrate on Android](docs/agents/android.md) for the host setup.

The Go package is `github.com/lambdawalker/android.apexfission.email-verification/testhost`. Use a commit or your local checkout as described in [Integrate from Go](docs/agents/go.md).
